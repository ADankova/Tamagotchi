# Ключ подписи тестовых сборок

`debug.keystore` — постоянный ключ, которым подписывается тестовый APK из GitHub Actions.
Пока ключ один и тот же, новые сборки ставятся на телефон обычным обновлением, и сохранение питомца остаётся.

Это **отладочный** ключ со стандартными паролями Android (`android` / `android`, алиас `androiddebugkey`),
поэтому он лежит в репозитории открыто. Для публикации в Google Play нужен отдельный ключ, который хранится
в секретах GitHub, а не в коде.

Отпечаток SHA-256 (сборка сверяет его с подписью APK):

```
86:63:04:51:B4:6C:7F:77:BA:65:E5:5A:CC:3F:61:63:79:F3:53:41:3E:58:C8:21:04:F1:CE:4C:DC:CD:BD:8A
```
